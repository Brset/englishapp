# Модели

Справочник моделей машинного обучения для оффлайн-приложения произношения английского языка.

## Содержимое

- `manifest.json` — реестр всех моделей с URL и контрольными суммами
- `fetch_models.py` (в папке `tools`) — скрипт для загрузки и проверки моделей

## Модели

- **Whisper** — распознавание речи
- **Silero VAD** — определение активности голоса
- **wav2vec2** — распознавание фонем
- **Piper** — синтез речи
- **CMUdict** — словарь произношения

## Использование

```bash
python tools/fetch_models.py          # Загрузить все модели
python tools/fetch_models.py --only whisper-base-en  # Загрузить одну
```

Файлы моделей не отслеживаются в Git (см. `.gitignore`).
